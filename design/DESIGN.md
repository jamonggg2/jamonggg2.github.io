# 디자인 규칙

개발자 포트폴리오 페이지의 디자인 규칙입니다. 새 화면을 만들거나 고칠 때 이 문서를 기준으로 합니다.

- 구조 참고: `ref01.png`(대시보드 홈), `ref02.png`(검색·필터가 있는 목록)
- 색상 참고: `ref03.png`(올리브 배경 + 검정 + 라임·라벤더·세이지 카드)
- 구현 파일: `css/custom.css` (Bootstrap인 `css/styles.css` **다음에** 불러와서 덮어씀)

> **용어**
> - **디자인 토큰**: 색·크기 같은 값에 이름을 붙여 한곳에 모아 둔 것. 값을 바꾸고 싶을 때 한 줄만 고치면 전체가 바뀜
> - **CSS 변수**: `--pf-bg` 처럼 이름 붙인 CSS 값. 코드에서는 `var(--pf-bg)` 로 꺼내 씀
> - **카드**: 둥근 모서리의 배경 상자. 관련 정보를 한 덩어리로 묶는 단위
> - **알약(pill)**: 양쪽 끝이 완전히 둥근 작은 버튼·태그 모양
> - **브레이크포인트**: 화면 너비에 따라 배치를 바꾸는 기준선

## 1. 페이지 구조

### 공통 뼈대 (모든 페이지)

```
┌──────────────────────────────────────────────┐
│ 헤더(검정) 로고 + 이름        홈 경력 프로젝트 연락처 │
├──────────────────────────────────────────────┤
│ 영문 작은 라벨 (eyebrow)                         │
│ 큰 제목 (h1)                                    │
│ 설명 한두 줄 (lead)                              │
│                                              │
│ 페이지별 본문                                    │
├──────────────────────────────────────────────┤
│ 푸터(검정)                                      │
└──────────────────────────────────────────────┘
```

- ref01처럼 **상단 헤더 + 카드 대시보드** 구조. 왼쪽 사이드바는 쓰지 않음
- 헤더: 정사각 로고(라임) + 이름 + 작은 대문자 부제(`DEVELOPER PORTFOLIO`). 오른쪽에 메뉴 알약. 현재 페이지는 라임 알약으로 표시
- 본문 폭은 최대 1360px, 좌우 여백은 화면에 따라 16~40px

| 페이지 | 파일 | 구조 | 참고 |

| 홈 | `index.html` | 큰 제목 → **프로필 카드 / 통계 카드 2개 / Core Stacks 타일 9개** 3단 대시보드 | ref01 |

## 2. 색상

ref03.png에서 실제 픽셀 값을 뽑아 정했습니다. 코드에서는 항상 **변수 이름**으로 씁니다. 색 값을 직접 쓰지 마세요.

### 기본 팔레트

| 변수 | 값 | 용도 |
|---|---|---|
| `--pf-bg` | `#4d6341` | 페이지 배경 (올리브 그린) |
| `--pf-ink` | `#141414` | 헤더·푸터·어두운 카드 배경, 밝은 카드 위 글자색 |
| `--pf-cream` | `#e7edcf` | 올리브/검정 배경 위 기본 글자색, 입력창 배경 |
| `--pf-muted` | `#d3dcb6` | 올리브 배경 위 보조 글자 (설명문, 라벨) |
| `--pf-lime` | `#deff86` | **주 강조색**. 현재 메뉴, 활성 토글, 주요 버튼, 로고 |
| `--pf-lavender` | `#dfc5fe` | 보조 강조 카드·배지 (프로필, 프리랜서) |
| `--pf-sage` | `#cbd6aa` | 중립 카드 (경력 행, 기본 카드), 어두운 배경 위 보조 글자 |
| `--pf-track` | `#8c9d6f` | 토글 바탕, 표 머리글 |
| `--pf-line` | `rgba(231,237,207,.28)` | 올리브 배경 위 얇은 테두리 |

### 사용 규칙

1. **배경 위 글자**: 올리브(`--pf-bg`)·검정(`--pf-ink`) 위에서는 `--pf-cream`(본문) / `--pf-muted`(보조)
2. **카드 위 글자**: 라임·라벤더·세이지·크림 카드 위에서는 항상 `--pf-ink`. 흰색·회색 글자 금지
3. **강조색은 한 화면에 한 곳이 주인공**: 라임을 가장 눈에 띄는 요소(현재 메뉴, 주 버튼)에 쓰고, 라벤더·세이지는 카드 구분용으로만 사용
4. **카드 색은 순서대로 돌려 쓰기**: 프로젝트 그리드는 라벤더 → 세이지 → 라임 순서 반복
5. **어두운 카드(`--pf-ink`)에서는** 아이콘만 라임, 글자는 크림, 보조 글자는 세이지
6. 새 색을 추가하지 않습니다. 필요하면 위 팔레트의 조합으로 해결

### 대비(글자와 배경의 밝기 차이) 확인

글자는 배경과 충분히 달라야 읽힙니다. 기준은 4.5:1 이상입니다.

- 크림 / 올리브 배경 ≈ 5.5:1 ✔
- 보조색(`--pf-muted`) / 올리브 배경 ≈ 4.6:1 ✔ (기준 턱걸이라 더 어두운 색으로 바꾸지 말 것)
- 잉크 / 세이지·라벤더 ≈ 12:1, 잉크 / 라임 ≈ 16:1 ✔
- 잉크 / 트랙(`#8c9d6f`) ≈ 6:1 ✔

## 5. 컴포넌트

### 버튼 `.pf-btn`
모노 글꼴, 알약 모양, 1.5px 테두리. 마우스를 올리면 잉크 배경 + 라임 글자로 반전.

| 종류 | 클래스 | 언제 |
|---|---|---|
| 기본(윤곽선) | `.pf-btn` | 밝은 카드 안의 보조 동작 |
| 라임 채움 | `.pf-btn--lime` | 어두운 카드 위 주 동작 |
| 잉크 채움 | `.pf-btn--ink` | 라임 카드 안의 제출 버튼 |
| 고스트 | `.pf-btn--ghost` | 올리브 배경 위 보조 동작 |

### 토글 `.pf-toggle`
ref03의 "Project-based learning / Guided classroom modules"와 같은 모양. `--pf-track` 바탕에 선택된 항목만 라임 알약 + 잉크 테두리. 선택 상태는 `aria-pressed` 로 표시합니다. (스크린리더도 읽을 수 있고, CSS 모양도 이 값을 따라감)

### 카드 `.pf-card`
기본은 세이지. `--lavender` `--lime` `--sage` `--dark` `--line` 으로 색을 바꿉니다. 카드마다 아이콘(1.75rem) → 제목 → 설명 순서.

### 태그 `.pf-pill--tag` / 배지 `.pf-badge`
- 태그: 담당업무·기술 이름. 반투명 검정 바탕, 작은 글씨
- 배지: 상태. 정규직 = 라임, 프리랜서 = 라벤더, 인턴 = 잉크(검정 바탕 + 크림 글자). 배지는 세이지 행 위에 놓이므로 세이지색 배지는 쓰지 않음

### 스킬 타일 `.pf-tile`
검정 배경, 라임 아이콘(2rem), 이름(굵게), 숙련도(모노, 세이지). 숙련도 단계는 `Expert > Advanced > Proficient` 세 가지만 씁니다.

### 검색창 `.pf-search`
알약 모양, 크림 배경, 왼쪽에 돋보기 아이콘. 글자를 칠 때마다 목록이 바로 걸러집니다 (`js/scripts.js`).

### 경력 행 `.pf-row`
세이지 카드 한 줄. 행 전체가 버튼이라 눌러서 상세를 펼치고(▾ 아이콘이 회전), 키보드로도 열 수 있습니다.

### 상태 표시
- **포커스 링**(키보드로 이동할 때 보이는 테두리): 잉크 2px 선 + 라임 5px 바깥 링. 어두운 배경과 밝은 배경 어디서든 둘 중 하나는 보이도록 이중으로 만듦
- 빈 결과: 가운데 정렬 모노 글씨 `조건에 맞는 … 이 없습니다.`

## 6. 아이콘

- Bootstrap Icons(`bi bi-…`) 사용. 외곽선 스타일로 통일
- 색은 주변 글자색을 따르고, 어두운 카드 위에서만 라임
- 장식용 아이콘에는 `aria-hidden="true"` (스크린리더가 읽지 않게 함)

## 8. 접근성 규칙

- 한 페이지에 `h1` 은 하나
- 이미지에는 `alt`, 장식 아이콘에는 `aria-hidden="true"`
- 현재 페이지 메뉴에 `aria-current="page"`
- 입력칸에는 반드시 `<label>` 연결
- 마우스 없이 키보드(Tab)만으로도 모든 버튼·링크 사용 가능해야 함
- 글자·배경 대비 4.5:1 이상 (2번 항목 참고)

## 9. 지키기 어려운 규칙 모음 (체크리스트)

새 화면을 추가할 때 확인하세요.

- [ ] 색 값(`#xxxxxx`)을 직접 쓰지 않고 `var(--pf-…)` 를 썼나
- [ ] 카드 위 글자가 잉크(`--pf-ink`)인가
- [ ] 한 화면에서 라임이 주인공 한 곳에만 쓰였나
- [ ] 그림자를 쓰지 않았나
- [ ] 라벨·버튼은 모노, 제목·본문은 산세리프인가
- [ ] 클래스 이름이 `pf-` 로 시작하나 (Bootstrap 기본 클래스와 섞이지 않게)
- [ ] 좁은 화면(모바일)에서 가로 스크롤이 생기지 않나

## 10. 샘플 텍스트 안내

현재 HTML의 이름(조성환), 경력, 프로젝트, 이메일(`hello@example.com`)은 모두 **샘플**입니다. 실제 내용으로 바꿀 때는 구조와 클래스는 그대로 두고 글자만 교체하세요. 문의 폼은 메일 앱을 여는 방식(`mailto:`)이라 실제 서버 전송은 되지 않습니다.
